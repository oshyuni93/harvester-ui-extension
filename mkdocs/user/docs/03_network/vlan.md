# VM 네트워크 (VLAN) 설정

> 클러스터 네트워크 구성에서 VM 네트워크를 생성합니다.

---

## STEP 1. 클러스터 네트워크 생성 (ext-net)

**경로:** 네트워크 → **클러스터 네트워크 구성** → **클러스터 네트워크 생성** 버튼

### ext-net 생성

| 항목 | 입력값 |
|------|--------|
| **이름** | `ext-net` |

**생성** 버튼 클릭

!!! info "역할"
    `ext-net`은 VM 네트워크와 연결할 클러스터 네트워크입니다.

---

## STEP 2. 네트워크 구성 생성 (extconfig)

생성된 `ext-net` 클러스터 네트워크 선택 → **네트워크 구성 생성** 버튼

### 기본 정보

| 항목 | 입력값 |
|------|--------|
| **이름** | `extconfig` |
| **노드 선택기** | `모든 노드 선택` |

!!! note "노드 선택기"
    - 클러스터 노드: **모든 노드 선택**
    - 싱글 노드: **특정 노드 선택**

### Uplink 설정

| 항목 | 입력값 |
|------|--------|
| **NICs** | `ens1f0` 선택 |
| **속성 MTU** | `1500` |

**생성** 버튼 클릭

---

## STEP 3. 가상 머신 네트워크 생성 (VLAN)

**경로:** 네트워크 → **가상 머신 네트워크** → **생성** 버튼

### 기본 정보

| 항목 | 입력값 |
|------|--------|
| **네임스페이스** | `default` |
| **이름** | `vlan102-net` |
| **유형** | `L2VlanNetwork` |
| **VLAN ID** | `102` |
| **클러스터 네트워크** | `ext-net` |

!!! tip "VLAN 추가 생성"
    vlan 103, 104도 동일하게 생성합니다.

### 라우트 설정

| 항목 | 입력값 |
|------|--------|
| **모드** | `수동` (단일 VLAN 사용 시 자동 설정) |
| **CIDR** | `192.168.102.0/24` |
| **게이트웨이** | `192.168.102.1` |

**생성** 버튼 클릭

### 연결 확인

생성 완료 후 가상 머신 네트워크 목록에서 확인:

| 이름 | 네트워크 유형 | 클러스터 네트워크 | VLAN ID |
|------|-------------|-----------------|---------|
| vlan101-net | L2VlanNetwork | ext-net | 101 |
