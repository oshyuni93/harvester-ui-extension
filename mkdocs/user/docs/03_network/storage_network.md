# Storage 네트워크 설정

> 클러스터 네트워크 구성에서 Storage 네트워크를 생성합니다.

---

## STEP 1. 클러스터 네트워크 생성 (storage-net)

**경로:** 네트워크 → **클러스터 네트워크 구성** → **클러스터 네트워크 생성** 버튼

| 항목 | 입력값 |
|------|--------|
| **이름** | `storage-net` |

**생성** 버튼 클릭

---

## STEP 2. 네트워크 구성 생성 (storage-config)

생성된 `storage-net` 선택 → **네트워크 구성 생성** 버튼

### 기본 정보

| 항목 | 입력값 |
|------|--------|
| **이름** | `storage-config` |
| **노드 선택기** | `모든 노드 선택` |

### Uplink 설정

| 항목 | 입력값 |
|------|--------|
| **NICs** | `ens2f1` 선택 |

**생성** 버튼 클릭

---

## STEP 3. storage-network 연결 설정

**경로:** 고급 → **설정** → 고급 탭 → **storage-network** 항목 → **설정 편집**

### storage-network 설정값

| 항목 | 입력값 |
|------|--------|
| **활성화됨** | ✅ 선택 |
| **유형** | `L2VlanNetwork` |
| **VLAN ID** | `101` |
| **클러스터 네트워크** | `storage-net` |
| **IP 범위** | `192.168.101.0/24` |
| **제외** | `192.168.101.1/32` |

**저장** 버튼 클릭

!!! warning "주의사항"
    스토리지 네트워크를 변경하면 이 설정을 완료하기 전에 모든 가상 머신을 꺼야 합니다. 사용자는 클러스터 네트워크가 구성되지 않은 노드를 플로팅하는 노드에서 네트워크 연결을 확인하고 모든 노드에서 네트워크 연결이 정상인지 확인해야 합니다.

### 연결 확인

설정 완료 후 storage-network 상태가 아래와 같이 표시됩니다:

```json
{
  "vlan": 101,
  "clusterNetwork": "storage-net",
  "range": "192.168.101.0/24",
  "exclude": ["192.168.101.1/32"]
}
```
