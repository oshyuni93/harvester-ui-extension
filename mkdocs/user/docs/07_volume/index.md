# 7. 볼륨 관리

> 가상 머신(VM)의 신속한 DISK 관리

---

## 볼륨 개요

Infinitystack의 볼륨은 Longhorn 기반의 분산 스토리지 볼륨으로, VM에 추가 디스크로 연결할 수 있습니다.

```
┌─────────────────────┐
│   Infinitystack     │
│  ┌───┐ ┌───┐ ┌───┐  │
│  │VM │ │VM │ │VM │  │
│  └─┬─┘ └─┬─┘ └─┬─┘  │
│    └──────┴──────┘   │
│         ↑            │
│  ┌──────────────┐    │
│  │ Storage      │    │
│  │ Volume       │    │
│  │ (Longhorn)   │    │
│  └──────────────┘    │
└─────────────────────┘
```

---

## STEP 1. 볼륨 생성

**경로:** 좌측 메뉴 → **볼륨** → **생성** 버튼

| 항목 | 입력값 |
|------|--------|
| **네임스페이스** | `default` |
| **이름** | `data-disk` |
| **기본 소스** | `새로운` |
| **스토리지 클래스** | `longhorn` |
| **크기 (Disk Size)** | `20` GB |

**생성** 버튼 클릭

!!! info "사전 작업 목적"
    볼륨을 먼저 생성해두면, VM에서 **볼륨 추가** 시 선택하여 바로 연결할 수 있습니다.

---

## STEP 2. 볼륨 생성 확인

볼륨 목록에서 생성된 `data-disk` 상태 확인:

| 항목 | 확인 내용 |
|------|----------|
| **상태** | `Ready` |
| **스토리지 클래스** | `longhorn` 또는 `harvester-longhorn` |
| **크기** | `20Gi` |
| **연결된 가상 머신** | (초기에는 비어있음) |

---

## STEP 3. VM에 볼륨 추가

**경로:** VM 목록 → 해당 VM(예: `barastack`) → 우측 메뉴(⋮) → **볼륨 추가**

| 항목 | 입력값 |
|------|--------|
| **이름** | `data-disk` 입력 |
| **볼륨** | `data-disk` 선택 |

**적용** 버튼 클릭

!!! success "마운트 완료"
    이미 생성한 볼륨 `data-disk`를 선택하고 적용을 누르면 가상 머신에 마운트됩니다.
    이후 VM 내에서 파티션 생성 및 마운트 작업이 필요합니다.
    자세한 내용은 [VM 볼륨 마운트](../06_vm/volume.md)를 참고하세요.
