# 1. 로그인 및 암호 설정

> 초기 암호 설정 및 암호 변경으로 보안 강화

---

## 초기 Admin 계정 암호 설정

최초 로그인 시 기존 admin 계정의 임시 비밀번호를 설정합니다.

### 접속 방법
브라우저에서 Infinitystack VIP 주소로 접속하면 초기 암호 설정 화면이 표시됩니다.

### 입력 항목

| 항목 | 입력값 |
|------|--------|
| **사용자 이름** | `admin` |
| **비밀번호** | 설치 시 입력한 비밀번호 |

!!! warning "계정 관리"
    확장된 계정 관리를 위해 Infinitystack은 별도의 추가적인 제품 플랜을 제시합니다.

---

## 암호 변경

로그인 후 언제든지 비밀번호를 변경할 수 있습니다.

**경로:** 계정 정보 → **계정 및 API 키** → **비밀번호 변경**

### 입력 항목

| 항목 | 예시 |
|------|------|
| **현재의 비밀번호** | `kkadmin@1q2w3e!!` |
| **새 비밀번호** | `dkfmzkeldk@1q2w3e4r!!` |
| **비밀번호 확인** | `dkfmzkeldk@1q2w3e4r!!` |

**적용** 버튼을 눌러 비밀번호 변경을 완료합니다.

!!! tip "안전한 비밀번호"
    비밀번호는 영문 대소문자, 숫자, 특수문자를 조합하여 8자 이상으로 설정하는 것을 권장합니다.
