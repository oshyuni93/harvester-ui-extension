# IP 풀 구성

> 로드밸런서에서 풀 방식으로 적용할 때 사용하는 IP 풀을 구성합니다.

---

## 사전 준비 - VM을 Management Network에 연결

로드밸런서는 Infinitystack에서 Mgmt Network 기반으로 서비스를 제공합니다.

**VM 생성 시 네트워크 설정:**

| 항목 | 입력값 |
|------|--------|
| **네트워크 이름** | `default` |
| **네트워크** | `Management Network` 선택 |
| **유형** | `masquerade` |

생성 후 VM 목록에서 **Management Network IP 대역** (`10.x.x.x`) 확인

---

## IP 풀 생성

**경로:** 네트워크 → **IP 풀** → **생성** 버튼

### 기본 정보

| 항목 | 입력값 |
|------|--------|
| **이름** | `vlan100-pool` |

### 범위 추가

| 항목 | 입력값 |
|------|--------|
| **서브넷** | `192.168.100.0/24` |
| **게이트웨이** | `192.168.100.1` |
| **시작 IP** | `192.168.100.11` |
| **끝 IP** | `192.168.100.100` |

!!! note "사용 범위"
    L3 switch의 vlan100의 Mgmt Network만 사용합니다.

**생성** 버튼 클릭

---

## 수집기 설정

IP 풀 생성 후 **수집기** 탭:

| 항목 | 설정 |
|------|------|
| **가상 머신 네트워크** | **없음** (management Network 사용 시 선택하지 않음) |

!!! warning "수집기 설정 주의"
    `management Network`를 사용하는 IP 풀은 수집기의 가상 머신 네트워크를 선택하지 않습니다.

---
