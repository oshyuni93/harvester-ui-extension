# 로드밸런서 생성

---

## STEP 1. 로드밸런서 생성 메뉴

**경로:** 네트워크 → **로드 밸런서** → **생성** 버튼

---

## STEP 2. 기본 정보 입력

| 항목 | 입력값 |
|------|--------|
| **네임스페이스** | `default` |
| **이름** | `homepage-lb` (예시) |
| **IPAM** | `풀` 선택 |
| **IP 풀** | `vlan100-pool` |

---

## STEP 3. 리스너 설정

| 항목 | 입력값 |
|------|--------|
| **이름** | `http-port` |
| **프로토콜** | `TCP` |
| **포트** | `8080` |
| **백앤드 포트** | `80` |

**추가** 버튼 클릭

---

## STEP 4. 백앤드 서버 선택기 설정

VM을 레이블로 선택합니다.

| 항목 | 입력값 |
|------|--------|
| **키** | `harvesterhci.io/vmName` |
| **값** | `homepage` (대상 VM 이름) |

**추가** 버튼 클릭

!!! info "백앤드 서버 연결 확인"
    백앤드 서버가 성공적으로 연결이 되면 상태가 `Not Ready`에서 `Active`로 변경됩니다.

**생성** 버튼 클릭

---

## STEP 5. 로드밸런서 확인

생성된 로드밸런서 목록에서 확인:

| 이름 | 주소 | 백앤드 유형 | IPAM |
|------|------|------------|------|
| homepage-lb | `192.168.100.11:8080` | 가상 머신 | 풀 |
| homepage-remote | `192.168.100.12:22` | 가상 머신 | 풀 |

---

## STEP 6. 접속 확인

| 로드밸런서 | 접속 URL | 용도 |
|-----------|---------|------|
| `homepage-lb` | `http://192.168.100.11:8080` | 웹 서비스 접속 |
| `homepage-remote` | `192.168.100.12:22` | VM 원격 접속(SSH) |

```bash
# 웹 서비스 접속 확인
curl http://192.168.100.11:8080

# VM SSH 접속 확인
ssh ubuntu@192.168.100.12
```
