# 9. 백업 관리

> 가상 머신(VM)의 안정적인 백업

---

## 개요

Infinitystack은 **MinIO(S3 호환 오브젝트 스토리지)** 또는 **NFS**를 백업 서버로 사용하여 VM 백업을 외부에 안전하게 보관합니다.

```
┌─────────────────────────────────────────────────┐
│                Infinitystack                    │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐         │
│  │ Cluster1 │ │ Cluster2 │ │ Cluster3 │         │
│  │ VM VM VM │ │ VM VM VM │ │ VM VM VM │         │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘         │
│       └────────────┴────────────┘                │
│                     ↓ 백업                       │
└─────────────────────────────────────────────────┘
                      ↓
           ┌──────────────────┐
           │   MinIO Server   │
           │  (S3 Compatible) │
           └──────────────────┘
```
