# 백업 설정 및 복원

---

## STEP 1. backup-target 설정

Infinitystack에서 외부 백업 서버를 연결합니다.

**경로:** 고급 → **설정** → **backup-target** → **설정 편집**

### 설정 값

| 항목 | 입력값 |
|------|--------|
| **유형** | `S3` (objectstorage) |
| **Endpoint** | `http://192.168.219.250:9000` (백업서버 IP) |
| **Bucket Name** | `infinitystack` |
| **Bucket Region** | `infinitystack` |
| **Access Key ID** | `minioadmin` |
| **Secret Access Key** | `minioadmin` |
| **Virtual Hosted Style** | `False` |

**저장** 버튼 클릭

!!! warning "Virtual Hosted Style"
    MinIO를 사용하는 경우 반드시 `False`로 설정합니다.

---

## STEP 2. 자동 백업 일정 설정

**경로:** 백업 및 스냅샷 → **가상 머신 일정** → **일정 만들기** 버튼

### 일정 만들기 설정

| 항목 | 입력값 |
|------|--------|
| **유형** | `백업` 선택 |
| **네임스페이스** | `default` |
| **가상 머신 이름** | `barastack` (예시) |
| **기본 크론 일정** | `0 0 1 * *` |

**크론 일정 예시:**

| 일정 | 크론 표현식 | 설명 |
|------|------------|------|
| 매일 자정 | `0 0 * * *` | 매일 오전 12시 |
| 매일 오전 1시 | `0 1 * * *` | 매일 오전 1시 |
| 매월 1일 | `0 0 1 * *` | 매월 1일 자정 |
| 매주 일요일 | `0 0 * * 0` | 매주 일요일 자정 |

!!! info "크론 포맷"
    일반적인 cron 포맷을 적용합니다: `분 시 일 월 요일`

**생성** 버튼 클릭

---

## STEP 3. 백업 목록 확인

**경로:** 백업 및 스냅샷 → **가상 머신 백업**

VM 백업 목록에서 수행된 백업을 조회할 수 있습니다:

| 이름 | 소스 VM | 가상 머신 일정 | 백업 대상 | 상태 |
|------|---------|--------------|----------|------|
| barastack-back | barastack | - | http://192.168.219.250:9000 | 완료됨 |

---

## STEP 4. 백업에서 VM 복원

**경로:** 백업 및 스냅샷 → **가상 머신 백업** → 해당 백업 우측 메뉴(⋮) → **새로 복원**

### 복원 설정

| 항목 | 입력값 |
|------|--------|
| **복원 방식** | `새로 만들기` (백업본으로 새로운 가상 머신 생성) |
| **네임스페이스** | `default` |
| **가상 머신 이름** | `barastack-2` (예시) |
| **백업 목록** | `barastack-back` 선택 |

**생성** 버튼 클릭

!!! success "복원 완료"
    복원이 완료되면 새 VM `barastack-2`가 VM 목록에 나타납니다.

!!! tip "기존 교체 복원"
    **기존 교체** 탭을 선택하면 기존 VM을 백업 상태로 덮어씁니다.
