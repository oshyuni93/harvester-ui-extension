# VM 생성

---

## STEP 1. VM 생성 메뉴 접속

**경로:** 좌측 메뉴 → **가상 머신** → **생성** 버튼

---

## STEP 2. 기본 정보 입력

| 항목 | 입력값 |
|------|--------|
| **네임스페이스** | `default` |
| **VM 이름** | `barastack` (예시) |
| **CPU** | `4` vCPU |
| **메모리** | `8` GB |
| **SSH 키** | `default/default-key` |

---

## STEP 3. 볼륨 설정

| 항목 | 입력값 |
|------|--------|
| **이미지 볼륨 이름** | `disk-0` |
| **유형** | `disk` |
| **이미지** | `default/ubuntu2204` 선택 |
| **크기** | `10` GB |
| **버스** | `VirtIO` |

!!! info "볼륨 크기 안내"
    생성된 볼륨은 OS 영역입니다. 데이터 디스크를 추가하려면 **볼륨 생성을 선행으로 작업**하고 볼륨 추가를 수행해야 합니다.

---

## STEP 4. 네트워크 설정 (DHCP IP 할당)

| 항목 | 입력값 |
|------|--------|
| **네트워크 이름** | `default` |
| **네트워크 모델** | `virtio` |
| **네트워크** | `default/vlan101-net` (VM 가상 네트워크인) |

!!! tip "다중 네트워크"
    다른 VM 가상 네트워크 연결이 필요할 때 **네트워크 추가** 버튼으로 추가합니다.

---

## STEP 5. 생성 완료 확인

**생성** 버튼 클릭 후 VM 목록에서 상태 확인:

| 항목 | 확인 내용 |
|------|----------|
| **상태** | `Running` |
| **IP 주소** | `192.168.101.34` (DHCP 할당) |
| **접속** | `Console` 버튼으로 원격 접속 가능 |

!!! note "IP 할당 방식"
    L3 switch의 DHCP Server에서 IP를 할당합니다.
    VM을 SSH 키로 생성했다면, 별도 ssh 키로 접속할 수 있는 접속 도구를 사용해야 합니다.
